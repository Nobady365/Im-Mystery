GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html from this folder.
3. Commit the file.
4. Go to Settings > Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select your main branch and the / (root) folder.
7. Save and wait for GitHub Pages to publish.

The website is intentionally a single index.html file, so it is easy to launch on GitHub Pages.
